# HOT CELL

A first-person cooperative game about dismantling a dead nuclear facility. A crew of four to six handles radioactive material through physical procedures. Mistakes can be accidental or deliberate, and some shifts have no traitor.

This repository contains the design brief. It does not yet contain game code or a playable build.

## Build brief

Read [the complete HOT CELL build brief](docs/BUILD_BRIEF.md) for the mechanics, interface rules, technical architecture, prototype scope, and milestones.

The supplied brief is preserved unchanged.

## First milestone

Build the Unity 6 grey-box prototype described in section 8, then run its four-player test before starting the art pass.

The central design rule is that innocent crew members and traitors have the same actions. Intent and private information create the uncertainty.
